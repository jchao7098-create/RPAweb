# frontend

AI Tools web 前端（Vue 3 + Vite + Element Plus 按需引入）。

- 项目架构、目录结构、本地开发步骤：见根目录 [README.md](../README.md)
- 代码约定（http 实例、懒加载、设计令牌等）：见根目录 [CLAUDE.md](../CLAUDE.md)
- 部署：见根目录 [DEPLOY.md](../DEPLOY.md)

```sh
npm ci        # 按 lockfile 安装
npm run dev   # 开发（接口指向本机后端，见 .env.development）
npm run build # 生产构建，产物在 dist/
```
