# 管理端实习生趋势图点击收起设计

## 目标

管理员在实习生明细中点击一行后展示该实习生的趋势图；再次点击同一行时收起趋势图，不新增关闭按钮。

## 交互规则

- 当前没有选中人员时，点击实习生行：选中该人员、请求趋势数据并展示图表。
- 已选中人员时，再次点击同一 `user_id` 的行：立即清空选中人员和趋势数据，图表收起，不再次请求趋势接口。
- 已选中人员时，点击另一 `user_id` 的行：切换选中人员、请求新人员趋势并保持图表展开。
- 行内“退回修改”按钮继续使用事件阻止，不触发展开或收起。
- 周次切换时，只有当前仍有选中人员才重新加载趋势。

## 修改范围

只修改前端 `LearningStats` 组件的行点击状态切换逻辑及对应组件测试；不修改后端接口、趋势数据结构或图表组件。

## 验收标准

- 第一次点击同一行后趋势图可见，趋势接口调用一次。
- 第二次点击同一行后趋势图不可见，趋势接口调用次数仍为一次。
- 点击不同人员仍能正常切换并加载对应趋势。
- 现有统计指标、退回功能和趋势图渲染测试继续通过。
