# 管理员入口学习统计查看权限设计

- 日期：2026-07-22
- 状态：已实施并通过自动化验证
- 项目：AI Tools web / RPA 项目管理系统

## 1. 目标与范围

现有项目已经包含实习生学习周报、学习统计、个人趋势、周报退回和人员角色管理功能。本次变更不重建学习模块，只调整管理员查看学习统计的授权口径：凡通过现有管理员登录入口 `/admin/login` 成功登录的账号，都可以查看全部实习生的学习统计。

“可以查看”仅包含周汇总、实习生明细和个人趋势。退回周报、调整角色及查看角色审计仍属于管理操作，只允许当前学习角色为 `hr` 或 `boss` 的账号执行。

本次不修正现有管理员入口允许任意注册账号登录的历史行为；管理员身份按登录入口判断，这是用户明确确认的业务规则。

## 2. 鉴权设计

学习模块继续使用已有签名令牌。令牌载荷新增必填字段 `login_surface`：

- 从 `/user/login` 登录时签发 `user`；
- 从 `/admin/login` 登录时签发 `admin`。

令牌校验必须同时验证用途标识、用户 ID 和登录入口。缺少 `login_surface` 的旧令牌视为无效，用户需要重新登录。后端不得信任前端传入的 `admin_id`、查询参数或本地缓存来判断管理员入口身份。

`GET /learning/me` 根据令牌入口与当前学习角色返回独立能力标记：

- `can_view_learning_stats`：`login_surface == 'admin'`；
- `can_manage_learning`：`login_surface == 'admin'` 且当前学习角色为 `hr` 或 `boss`；
- 实习生周报相关能力仍按学习角色和当周名册判断，并且只对用户入口开放。

## 3. 接口权限

以下只读接口允许所有 `admin` 入口令牌访问：

- `GET /learning/admin/weekly-stats`
- `GET /learning/admin/users/<user_id>/trend`

以下写操作和敏感管理接口继续要求 `admin` 入口令牌，且当前学习角色必须为 `hr` 或 `boss`：

- `POST /learning/admin/reports/<report_id>/return`
- `GET /learning/admin/users`
- `PATCH /learning/admin/users/<user_id>/role`
- `GET /learning/admin/role-change-logs`

所有用户端周报接口只接受 `user` 入口令牌，并继续执行实习生角色、周名册、记录归属和状态校验。这样可防止管理员入口令牌绕过用户端周报资格，也可防止用户入口令牌读取全员统计。

## 4. 前端行为

管理员工作台根据 `/learning/me` 的 `can_view_learning_stats` 显示“学习统计”。因此所有从管理员入口登录的账号均能看到该模块。

“人员权限”入口继续根据 `can_manage_learning` 显示，仅 HR 和老板可见。学习统计页面中的“退回修改”按钮同样由 `can_manage_learning` 控制；普通管理员只看到指标、实习生明细和个人趋势。

用户工作台继续只为具备实习生周报能力的账号显示“学习周报”，不显示全员统计。

## 5. 数据与统计口径

本次不新增数据表，不修改共享 MySQL。学习角色、周名册、周报、正式提交和退回日志继续存放在本地 `backend/var/assets.db`。

统计口径保持不变：

- 已提交只计算最新有效正式提交；
- 草稿、缺失、退回修改中和退回逾期记录不计入已提交指标；
- 总学习时长和平均完成度只聚合有效正式提交；
- 周名册决定当周应提交的实习生集合。

## 6. 错误处理与兼容性

- 缺失、伪造、过期或缺少入口字段的学习令牌返回 `401`，前端清除学习会话并提示重新登录；
- `user` 入口令牌访问全员统计返回 `403`；
- 普通管理员调用退回、角色或审计接口返回 `403`；
- 数据校验、并发冲突和既有统计异常继续沿用学习模块现有的 `422`、`409` 等响应约定。

令牌结构变化会使正在使用的旧学习令牌失效，这是一次可接受的主动重新登录，不进行兼容降级，避免旧令牌无法区分登录入口而造成越权。

## 7. 验证范围

后端自动化测试覆盖：

- 用户登录与管理员登录签发不同入口的学习令牌；
- 普通管理员可以读取周统计和个人趋势；
- 用户入口令牌不能读取全员统计；
- 普通管理员不能退回周报或访问角色管理接口；
- HR/老板从管理员入口登录后保留全部既有管理能力；
- 旧格式令牌被拒绝并返回 `401`。

前端自动化测试覆盖：

- 普通管理员显示“学习统计”但不显示“人员权限”；
- 普通管理员在统计页面不显示“退回修改”；
- HR/老板继续显示管理入口和退回操作；
- 用户工作台不显示全员统计入口。
