# 管理端最近一周实习生 RPA 学习情况导出设计

## 目标

在管理员端“数据导出”模块增加实习生 RPA 学习情况下载入口，以 Excel 可直接打开的 UTF-8 BOM CSV 导出上海时区当前自然周的数据。

## 时间与人员口径

- “最近一周”指上海时区当前自然周，周一至周日。
- 统计周在每行中显示为 `YYYY年MM月DD日—YYYY年MM月DD日`，例如 `2026年07月20日—2026年07月26日`。
- 导出当前周冻结名册中的全部实习生；未提交人员也保留一行。

## 数据口径

- CSV 列顺序固定为：统计周、用户名、邮箱、提交状态、学习内容、学习时长（小时）、完成度（%）、备注、正式提交时间。
- 只导出当前有效的最新正式提交版本；未提交草稿不进入内容、时长、完成度、备注和提交时间列。
- 当前有效正式版本的状态显示“已提交”。
- `missing` 或 `draft` 显示“未提交”；`returned` 显示“退回修改中”；`return_expired` 显示“退回逾期”。这些状态的数据列留空，因为当前不计为有效正式提交。
- 正式提交时间按上海时区显示为 `YYYY-MM-DD HH:mm`。
- CSV 使用标准转义处理逗号、引号和换行；用户输入以 `= + - @` 开头时按文本输出，避免 Excel 公式执行。

## 前端交互

- 在现有两张导出卡片后新增“最近一周实习生 RPA 学习情况”卡片。
- 点击“下载学习情况表”后复用现有 Blob 下载流程。
- 下载文件名为 `实习生RPA学习情况_YYYY-MM-DD.csv`，日期取当前周周一。
- 下载期间按钮显示加载状态，并与现有导出任务互斥；失败时显示现有统一错误提示。

## 后端接口与权限

- 新增 `/learning/admin/export/recent-week` GET 接口。
- 接口使用管理员登录面的学习令牌校验；所有通过管理员入口登录的账号均可访问，用户入口令牌返回 403。
- 后端复用学习统计的冻结名册、报告状态和最新正式提交口径，不修改数据库结构。
- 响应类型为 `text/csv; charset=utf-8`，正文以 UTF-8 BOM 开头，并带附件响应头。

## 测试与验收

- 后端测试覆盖 CSV BOM、中文表头、年月日统计周、已提交正式内容、未提交空列和管理员/用户入口权限。
- 前端测试覆盖新增卡片、学习导出 URL、Blob 下载文件名及加载键。
- 完整前端测试、生产构建和后端测试通过，本地站点继续返回 HTTP 200。
